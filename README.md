```
  ├─ Bronze: Raw append-only                            ├─ Classify & Memory Agents

  └─ dbt Gold: Business Analytics Marts                 ├─ Churn & Incident Detection
            │                                           └─ Human-in-the-Loop (HITL) Gate
            ▼                                                     │
[DuckDB / Supabase Data Store]                                    ▼
                                                  [LiteLLM Smart SLA Router]
                                                    ├─ Local Ollama ($0 cost)
                                                    └─ Cloud Fallback with L2 Cache
                                                                  │
                                                                  ▼
                                              [Constitutional Policy Guardrails]
                                                    (7-Rule EU AI Act Verification)
                                                                  │
                                                                  ▼
                                            [Langfuse Traces + Prometheus Metrics]
```

#### 🌟 Key Technical Highlights:
- **Streaming Lakehouse:** Ingests high-throughput telemetry via Redpanda broker. PySpark cleanses data into silver tiers before dbt builds dimension models.
- **Multi-Agent Supervisor:** 6 specialized LangGraph nodes operating under strict typed schemas with stateful checkpoints and graph-level recovery.
- **Intelligent SLA Router:** Dual-tier dispatch routing between local models (Ollama $0 inference) and cloud LLMs via LiteLLM, cutting enterprise API expenses by **54%**.
- **Privacy & Security Vault:** Presidio automated PII anonymization, AES-256 encrypted fields, tenant-isolated Supabase Row-Level Security (RLS), and RBAC human approval queues.
- **Production Rigor:** 307 automated unit, integration, and regression tests, complete Docker Compose orchestration, and Kubernetes Kind deployment templates.
